습관을 여쭙습니다

평소 생활습관을 꼼꼼하게 여쭙습니다. 앞머리는 최대한 내리지 않는 편이 좋고, 가능하면 머리를 묶는 습관을 들여 보시라고 말씀드리기도 합니다.

쓰시는 제품도 확인합니다

사용하고 계신 기초화장품을 하나씩 확인하면서 피부 타입에 맞는지 짚어 봅니다.

제품만 바꿔 보기보다 피부 상태를 먼저 확인하는 편이 도움이 됩니다.

핵심 정리

왜 여쭙나 — 원인이 진료실 바깥에 있을 때가 많습니다

앞머리 — 최대한 내리지 않는 편이 좋습니다

머리 — 가능하면 묶는 습관을 권해 드리기도 합니다

기초화장품 — 피부 타입에 맞는지 하나씩 확인합니다
