거울로 보이는 것과 촬영해서 보는 것이 다릅니다. 눈으로만 볼 때는 모르던 것을 촬영으로 확인합니다.

촬영해서 보는 것

피부를 촬영해 현재 상태를 자세하게 분석해 눈으로만 볼 때는 모르던 피지 분포나 모공 상태, 여드름이 반복되는 부위까지 하나씩 설명드립니다.

자기 피부를 처음 제대로 이해하게 됐다고 말씀하시는 분들이 많습니다.

같이 여쭙는 것

촬영으로 드러나는 것 말고 평소 습관도 여쭙습니다. 앞머리를 내리시는지, 머리를 묶으시는지 같은 것들입니다.

사용하고 계신 기초화장품도 하나씩 확인하면서 피부 타입에 맞는지 짚어 봅니다.

핵심 정리

무엇을 하나 — 피부를 촬영해 현재 상태를 분석합니다

무엇이 보이나 — 피지 분포 · 모공 상태 · 반복되는 부위

왜 하나 — 자기 피부를 제대로 이해하는 데서 시작합니다

함께 여쭙는 것 — 생활습관과 쓰시는 기초화장품
